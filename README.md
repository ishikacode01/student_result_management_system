
# Student Result Management System

## Project Description
The Student Result Management System is a C programming project developed as part of the PPS (Programming for Problem Solving) subject.

It helps manage student academic records, calculate total marks, percentage and grades.

## Features
- Add Student Details
- Store Roll Number and Name
- Enter Marks in 5 Subjects
- Calculate Total Marks
- Calculate Percentage
- Calculate Grades
- Display All Students
- Search Student by Roll Number

## Technologies Used
- C Programming Language
- Visual Studio Code
- GCC Compiler

## C Concepts Used
- Structures
- Arrays
- Functions
- Loops
- Conditional Statements
- Switch Case

## How to Run

1. Install GCC compiler.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   gcc main.c -o main

5. Run the program:

   .\main.exe
